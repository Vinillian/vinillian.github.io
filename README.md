

# 36 стратагем — энциклопедия древних стратегий

Этот сайт представляет собой полное собрание 36 классических китайских стратагем — стратегических приёмов,
которые веками использовались в военном деле, дипломатии, бизнесе и повседневной жизни.

## 📖 Что внутри

- **Главная страница** со списком всех стратагем, поиском и кратким описанием.
- **Индивидуальная страница** для каждой из 36 стратагем с примерами из истории, бизнеса и жизни.
- **Адаптивный дизайн** — удобно смотреть с компьютера, планшета или телефона.
- **Навигация** между стратагемами (предыдущая / следующая).

## 🛠️ Технологии

- HTML5
- CSS3
- JavaScript (чистый, без фреймворков)

### Как добавить этот текст в новый репозиторий

1. При создании нового репозитория `vinillian.github.io` поставьте галочку **"Add a README file"**.
2. GitHub создаст файл `README.md` с дефолтным содержимым.
3. Нажмите на него, затем на иконку карандаша (✏️ **Edit**).
4. Вставьте текст выше, полностью заменив старое содержимое.
5. Внизу нажмите **Commit changes**.

Если вы уже создали репозиторий без README, то нажмите **Add file** → **Create new file**, назовите его `README.md`, вставьте текст и сохраните.
